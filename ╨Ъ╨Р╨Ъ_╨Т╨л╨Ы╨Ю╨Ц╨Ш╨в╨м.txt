FIANCHETTO — КАК ВЫЛОЖИТЬ САЙТ БЕСПЛАТНО (GitHub Pages)

Нужен только браузер. Никаких программ и серверов.

1. Зарегистрируйтесь на https://github.com (бесплатно).
2. Нажмите «+» вверху справа → «New repository».
   Имя: fianchetto   ·   Public   ·   нажмите «Create repository».
3. На странице репозитория нажмите ссылку «uploading an existing file».
4. Распакуйте архив и ПЕРЕТАЩИТЕ ВСЁ СОДЕРЖИМОЕ этой папки
   (файл index.html и папки css, js, engine, lib, pieces) в окно браузера.
   Важно: index.html должен оказаться в корне, а не внутри папки.
5. Внизу нажмите «Commit changes» и подождите, пока файлы загрузятся.
6. Откройте вкладку «Settings» → слева «Pages».
   В «Branch» выберите «main» и папку «/ (root)» → «Save».
7. Через 1–2 минуты сайт будет по адресу:
   https://ВАШ-НИК.github.io/fianchetto/

КАК ОБНОВИТЬ УЖЕ ВЫЛОЖЕННЫЙ САЙТ (ваш случай):
1. Откройте репозиторий fianchetto на GitHub.
2. Нажмите «Add file» → «Upload files».
3. Перетащите ВСЁ СОДЕРЖИМОЕ новой папки (как в первый раз) — старые файлы заменятся новыми.
4. «Commit changes». Через 1–2 минуты сайт обновится (если нет — обновите страницу с Ctrl+F5).

Проверить сайт у себя без интернета: в этой папке нельзя просто открыть index.html двойным щелчком
(браузеры запрещают так запускать движок). Удобнее сразу выложить на GitHub Pages.
